# WYPE Security - Feature Graphic Template

## Specifications
- **Size:** 1024 x 500 pixels (exactly)
- **Format:** PNG or JPG
- **File size:** Max 15MB
- **Usage:** Main banner on Google Play Store listing

## Design Elements to Include:

### Text Elements:
1. **Main Headline:** "WYPE Security"
2. **Tagline:** "Voice-Activated Emergency Protection"
3. **Key Features:** (small text)
   - Emergency SMS Alerts
   - Automatic Device Wipe
   - Google Drive Backup
   - International Support

### Visual Elements:
1. **App Icon:** Place prominently (left side recommended)
2. **Background:** Use app theme colors or gradient
3. **Typography:** Bold, readable fonts
4. **Icons:** Small icons representing key features

## Color Scheme (from app):
- Primary colors from your app theme
- Ensure good contrast for readability
- Professional, security-focused palette

## Design Layout Suggestions:

### Layout Option 1: Left Icon, Right Text
```
[App Icon]  WYPE Security
            Voice-Activated Emergency Protection
            ✓ Emergency SMS  ✓ Device Wipe
            ✓ Cloud Backup   ✓ Global Support
```

### Layout Option 2: Centered Design
```
        [App Icon]
    WYPE Security
Voice-Activated Emergency Protection
[feature icons with text below]
```

### Layout Option 3: Action-Oriented
```
[App Icon] WYPE Security
           ULTIMATE EMERGENCY PROTECTION
           [Phone illustration] → [SMS icon] → [Cloud icon]
```

## Tools to Create Feature Graphic:

### Quick Online Tools:
1. **Canva.com**
   - Template: "Google Play Feature Graphic" 
   - Search for "app store banner"
   - Customize with WYPE branding

2. **Google Slides**
   - Set custom slide size to 1024x500 pixels
   - Design your graphic
   - Download as PNG

### Advanced Tools:
1. **Figma** (free web app)
2. **GIMP** (free desktop)
3. **Photoshop** (paid)

## Step-by-Step Canva Instructions:

1. **Go to Canva.com** and create free account
2. **Search for:** "Google Play Feature Graphic" or create custom size 1024x500
3. **Choose a template** or start blank
4. **Replace text with:**
   - "WYPE Security" (large, bold)
   - "Voice-Activated Emergency Protection" (subtitle)
5. **Upload app icon** (`app_icon_512.png` from our assets)
6. **Add feature icons** (microphone, SMS, cloud, shield)
7. **Adjust colors** to match your app theme
8. **Download as PNG** in high quality

## Final Tips:

1. **Keep it simple** - Feature graphics are viewed at small sizes
2. **Focus on benefits** rather than features
3. **Use contrasting colors** for readability
4. **Test readability** by viewing at smaller sizes
5. **Stay professional** - this represents your app
