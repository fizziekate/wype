# WYPE Security - Play Store Screenshots Guide

## Required Screenshots (Minimum 2, Recommended 4-8)

### Screenshot Requirements:
- **Phone:** 1080x1920 or 1440x2560 pixels
- **Format:** PNG or JPG
- **File size:** Max 8MB each
- **Content:** Must show actual app functionality

## Recommended Screenshots to Take:

### 1. Login/Welcome Screen ⭐ (Required)
- Shows app branding and initial user experience
- Clean, professional first impression

### 2. Home Screen - Protection Active ⭐ (Required)
- Show the main dashboard with protection status
- Service running indicator
- Main navigation visible

### 3. Record Wake Phrase Screen
- Shows voice recording functionality
- Recording controls and waveform
- Current phrase display

### 4. Buddy Contact Setup
- Emergency contact selection
- Phone number formatting
- International support visible

### 5. Google Backup Screen
- Cloud backup integration
- Google sign-in status
- Backup controls

### 6. Instructions/How It Works
- Step-by-step usage guide
- Clear explanation of features
- Professional layout

## How to Take Screenshots:

### Option 1: Using Android Device
1. Install the WYPE app on your Android device
2. Navigate through each screen
3. Take screenshots using Power + Volume Down
4. Transfer screenshots to computer

### Option 2: Using Android Studio Emulator
1. Open Android Studio
2. Start an emulator (Pixel 6 recommended)
3. Install and run WYPE APK
4. Use emulator screenshot tool
5. Save screenshots in 1080x1920 resolution

### Option 3: Using ADB Command
```bash
adb shell screencap -p /sdcard/screenshot.png
adb pull /sdcard/screenshot.png
```

## Screenshot Tips:

### ✅ DO:
- Use clean, uncluttered screens
- Show app in actual use
- Include realistic data (fake phone numbers okay)
- Ensure text is readable
- Use consistent device frame

### ❌ DON'T:
- Include personal/real contact information
- Show error states or broken functionality  
- Use blurry or low-quality images
- Include device status bar if possible
- Use placeholder or Lorem ipsum text

## File Naming Convention:
- `01_login_welcome.png`

- `03_record_wake_phrase.png`

## After Taking Screenshots:

1. **Review Quality:** Ensure all screenshots are clear and professional
2. **Check Content:** Verify no personal information is visible
3. **Resize if Needed:** Ensure proper dimensions
4. **Save to play_store_assets folder**

## Feature Graphic Requirements:

### Specifications:
- **Size:** 1024x500 pixels exactly
- **Format:** PNG or JPG
- **Content:** Promotional banner with app name and key features
- **Style:** Match app branding

### Feature Graphic Elements:
- WYPE Security logo/branding
- Key benefit text (e.g., "Voice-Activated Emergency Protection")
- App icon
- Professional design matching app theme
- Call to action implied
